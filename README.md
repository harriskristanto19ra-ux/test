# SAFELINK — Engineered Connection

A premium, single-page brand website concept for SAFELINK (安全鏈結):
cinematic and restrained, built on a minimal porcelain-white palette with
a single thread of safety orange.

## Design system

- **Typography** — Archivo (variable width/weight) for display,
  Instrument Serif for editorial italics, Space Grotesk for technical
  micro-labels, Noto Sans TC for Traditional Chinese accents.
- **Palette** — porcelain white `#FAFAF7`, ink `#131410`,
  safety orange `#FF4D00` (used sparingly).
- **Motion** — scroll reveals, animated stat counters, kinetic marquee,
  gentle hero parallax. Fully disabled under `prefers-reduced-motion`.
- **Responsive** — fluid `clamp()` type scale, overlay menu and stacked
  layouts on mobile.

## Stack

Zero dependencies — hand-written HTML/CSS/JS. Google Fonts is the only
external resource.

## Deploy

Pushes to `claude/premium-brand-website-korgyl` deploy automatically to
GitHub Pages via `.github/workflows/deploy.yml`.
